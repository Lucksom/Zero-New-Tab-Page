# Zero-New-Tab-Page

A highly customizable, minimalist Material Design New Tab extension. Features include a sleek Glassmorphism UI, a unique Dual Search Engine mode, live weather with canvas animations, and dynamic shortcuts.

## ✨ Features
* **Dual Search Mode:** Type once, choose between two active search engines instantly.
* **Live Weather UI:** Animated canvas weather effects that seamlessly match real-world conditions.
* **Total Customization:** Adjust icon shapes, UI transparency, and apply solid colors, gradients, or high-res image backgrounds.
* **Smart Shortcuts:** Fully draggable, editable quick-links grid.

## 🚀 How to Install
Zero-New-Tab-Page can be installed manually in just a few seconds:

1. Go to the [Releases page](../../releases) and download the latest `Zero-New-Tab-Page.zip` file.
2. Extract the downloaded file to a folder on your computer.
3. Open your Chromium-based browser and navigate to `chrome://extensions/` (or `edge://extensions/`).
4. Toggle on **Developer mode** in the top right corner.
5. Click the **Load unpacked** button in the top left.
6. Select your extracted `Zero-New-Tab-Page` folder.
7. Open a new tab and enjoy a cleaner home screen!
